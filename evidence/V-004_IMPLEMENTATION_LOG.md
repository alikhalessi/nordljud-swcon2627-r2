## Assistant implementation choices / limitations

- **Practice questions:** Multiple choice for exact English meaning, present form, and where a complete source example can be safely masked, fill-in-the-sentence. The cloze is generated by replacing an existing conjugated word inside the *original* Swedish sentence with underscores; reconstructable against stored Swedish and English text. Distractors use recorded other vocabulary meanings or inflection variants, never generated Swedish sentences.
- **Missing data:** A question type is omitted if the source lacks sufficient appropriate data or distinct options; do not invent grammar or translations to fill gaps. Every source entry can still be studied.
- **Selected senses:** Practice uses the selected `level + entry ID`; two `sticka` senses are distinct. Changing level resets questions but retains V-003 identity selection.
- **Scoring:** Screen-local only. Incorrect answers do not earn points; answering correctly marks that question solved. Retry and next are available, and the user may restart. No persistent progress or scores, no account.
- **Not claimed:** Natural-language/semantic answer disambiguation, independent professional Swedish review, voice heard on student's browser, actual E2E browser acceptance, mobile and accessibility audit, security certification. The static unit tests validate structural correctness and source provenance, not language pedagogical validity.
- **Research implementation caveat:** This assistant made technical choices not specified in the plain-language prompt. It is evidence of Vibe agent discretion, not an SDD-specification-led implementation.
